# CR-019 캐릭터 궁합·공유 설계와 근거

사용자 문제: 긴 설명을 읽기 전에 우리 조합, 통하는 부분, 맞춰볼 부분이 눈에 들어오지 않는다. 이미지·형상·캐릭터와 공유 동선을 강화한다. 사주 점수와 단정은 계속 사용하지 않는다.

Wrapped 두 자료는 커뮤니티 프로젝트이며 Spotify 공식 서비스 성과 자료가 아니다. README의 성과·유입 주장은 독립 검증하지 않았다. 공식 16personalities 사이트는 현재 프록시 정책 403으로 열람하지 못했다. 위 공개 코드·문서에서 패턴만 참고했으며 캐릭터/코드/이미지를 복사하지 않았다.

## 화면 변화

- 첫 화면: 원본 캐릭터 두 명과 “너랑 나, 무슨 조합일까?” 브랜드 문구. 가짜 궁합 예시는 없음.
- 친구가 없는 화면: 내 캐릭터 먼저 보기와 친구 초대. 존재하지 않는 상대 결과는 만들지 않음.
- 내 프로필: 자신의 일간 오행을 새싹·불꽃·중심·별·사색가 캐릭터로 비유.
- 궁합: pair 선택 → 큰 조합 이름/두 캐릭터 → 잘 통하는 점/맞춰볼 점 → 공유. 전체 모임 오행과 해석 원문은 펼쳐 읽기.
- 조합 분류는 기존 서버 facts의 알려진 코드로 결정하며 합산·백분율·등급을 만들지 않음. 충·상극 등 차이 신호가 있으면 시각적 제목에서도 다름을 드러내고 공통점도 함께 보여줌.
- 근거 원문과 사주/MBTI 구분, 출생시간 누락 안내를 유지. 질문은 선택한 pair에 맞추고 대화 입력창에만 담음.
- 모임별 유료 의향 질문은 궁합 핵심/공유 흐름에서 제거.

## 공유와 개인정보

공유 미리보기를 연 후 사용자가 공유 버튼을 누를 때만 native share를 호출한다. 준비된 파일로 사용자 동작을 유지한다. 지원하지 않거나 실패하면 PNG 다운로드, 취소는 완료로 표시하지 않는다.

이미지는 자체 카탈로그 문구와 도형으로 생성한다. 서버 fact.text/notes, 사용자 ID·이름·생년월일·메시지·모임/초대 URL은 넣지 않는다. 파일명도 고정한다. 링크는 공개 홈만 사용한다. 서비스 외부 자동전송·실제 개인 데이터 테스트 없음.

브랜드 OG 이미지는 SVG 도형을 Canvas로 변환한 공개 제품 자산이다. 사이트 캡처/사용자 보고서 이미지가 아니다. 브라우저 테스트는 화면 캡처와 파일 저장 없이 PNG 형식/크기/공유 인자를 검사한다.

## 효과와 검증의 구분

바이럴 증가는 아직 가설이다. 이번에는 결과를 빨리 파악하는 구조와 공유 동작을 구현했다. 강제 공유·허위 이용자 수·임의 궁합 점수는 넣지 않았다. 실제 공유율·초대 수락률은 사용자 테스트 뒤 판단한다.

새 DB/서버 배포·외부 이미지 API·새 패키지·유료 호출 없이 기존 궁합 응답을 사용한다. 접근성은 텍스트 결과, 모바일 360/390/430px, 색상 외 문구 구분, reduced-motion에서 애니메이션 없음으로 검증한다.
