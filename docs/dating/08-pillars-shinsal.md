# CR-025 — 내 원국과 날짜별 운을 함께 읽는 만세력

## 사용 흐름

테스트 사이트 `/try` → 내 사주 → 출생일·출생시간 선택 → 선택한 정보로 풀이 보기 → 원국·십신 또는 오늘/월간/연간 운세, 나의 대운.

| 화면 | 표시되는 것 | 눌러서 읽는 것 |
| --- | --- | --- |
| 내 원국 | 시주·일주·월주·연주 순서, 천간·지지, 오행 색, 십성 | 각 기둥 아래 신살의 뜻·성립 근거·생활 예시 |
| 선택한 운 | 선택 날짜의 일/월/연 간지, 또는 선택한 대운 간지 | **출생 원국의** 일간·월지·연지/일지로 대조한 신살 |
| 함께 읽기 | 실제 발견된 두 신살의 위치 | 두 관점을 함께 살펴볼 질문, 각각의 근거 |
| 기둥 사이 연결 | 원국끼리, 날짜 조회 시 원국과 운의 합·충 | 성립한 글자 쌍, 쉬운 의미와 예시 |
| 계산 기준 | 12신살 연지/일지, 백호 대조 범위 | 지원 범위·학파 차이·미상/경계 안내 |

출생 원국은 조회 날짜를 바꿔도 변하지 않는다. 출생시간 미상은 시주 **빈 칸**을 남기고 글자·십성·신살을 만들지 않는다. 절기 경계의 영향을 받는 항목은 `*`/`확인 필요`를 표시한다. 조회 날짜가 잘못되면 원국은 유지하고 운 및 운에서 선택한 상세 내용은 제거한다.

로그인 사용자와 공개 체험은 같은 `PersonalReading`/`ShinsalReading`을 사용한다. 실제 계정 DB·로그인·메시지·푸시·결제는 이번 변경에 포함하지 않는다. 출생 입력과 기준 선택을 새로 전송하거나 저장하지 않는다. 공개 체험 입력은 새로고침하면 초기화된다.

## 산출 규칙 v1

모든 설명은 새로 작성한 참고용 자기이해 문구다. 의료·안전·범죄·인격·연애 성공 여부를 판정하거나 수치화하지 않는다. 전통 이름에 포함된 ‘살’이나 ‘귀인’을 미래 사건의 원인으로 다루지 않는다.

| 항목 | 고정 기준 |
| --- | --- |
| 천을귀인 | 일간 갑/무/경→축미, 을/기→자신, 병/정→해유, 신→인오, 임/계→묘사 |
| 문창귀인 | 일간 갑을병정무기경신임계 → 사오신유신유해자인묘 |
| 천덕귀인 | 월지 인묘진사오미신유술해자축 → 천간 정 / 지지 신(申) / 천간 임 / 천간 신(辛) / 지지 해 / 천간 갑 / 천간 계 / 지지 인 / 천간 병 / 천간 을 / 지지 사 / 천간 경 |
| 월덕귀인 | 월지 인오술→병, 신자진→임, 사유축→경, 해묘미→갑 천간 |
| 양인살 | 양간 일간만: 갑→묘, 병/무→오, 경→유, 임→자. 음간 계산 제외 |
| 백호대살 | 갑진·을미·병술·정축·무진·임술·계축. 기본은 네 기둥·조회 운까지 **간지 해당 여부를 확장 비교**. 원국 일주만 보는 선택지도 제공 |
| 괴강살 | **원국 일주만**, 경진·경술·임진·무술 목록 채택 |
| 12신살 | 기본 원국 연지, 선택 시 원국 일지. 인오술→해, 사유축→인, 신자진→사, 해묘미→신에서 겁살을 시작, 지지 순서대로 12개 배치 |

12개 순서: 겁살·재살·천살·지살·연살(도화)·월살·망신살·장성살·반안살·역마살·육해살·화개살. 각 대상 지지에는 이 기준으로 하나가 배치된다. 개수가 많고 적음으로 좋고 나쁨이나 성격 강도를 판단하지 않는다.

지원 총 19종. **전 신살 분석은 아니다.** 공망·홍염·원진·귀문·12운성·지장간 전체, 형파해·삼합 종합은 미포함. 운의 백호는 확장 비교에서만, 괴강은 원국 일주에서만 계산한다. 원국·운을 비교할 때 기준점을 운의 일간이나 월지로 바꾸지 않는다.

합충은 신살과 별도 규칙이다. 천간합(갑기·을경·병신·정임·무계), 지지육합(자축·인해·묘술·진유·사신·오미), 지지충(자오·축미·인신·묘유·진술·사해)을 실제 두 글자로만 산출한다. 합화, 세력, 길흉, 사건 발생이나 신살 상쇄를 추정하지 않는다.

함께 읽기는 천을+백호, 문창+역마, 도화+화개, 월덕+양인 네 가지 편집 조합을 지원한다. 둘 다 실제 산출된 경우에만 각각의 위치와 근거를 보여준다. 신살 상호작용의 검증된 인과법칙을 주장하지 않는다. 같은 신살이 여러 위치에 있으면 조회 운의 위치를 우선하고 나머지는 표 순서로 대표 한 쌍을 고른다. 모든 위치는 각 기둥에서 따로 확인할 수 있다.

## 조사와 선택의 한계

확인일: 2026-10-16 KST. 기존 `manseryeok` 2.0.0 README는 신살·12운성을 제공하지 않는다고 밝힌다. 원국과 운 계산은 기존 엔진을 유지하고 독립 규칙 모듈을 추가했다. 기존 한국 시간·자정 경계·진태양시 보정 없음 설정도 유지한다.

공개 구현을 **표와 관례 차이의 비교 자료**로 읽었다. 이 자료들이 명리 해석의 과학적 타당성이나 모든 학파의 합의를 입증하는 것은 아니다.

- [rath/orrery 상수표](https://github.com/rath/orrery/blob/b49bffb0e7031ce5b7a3a71e317f5cf9ffc6cf3a/packages/core/src/constants.ts): 천을·문창·천덕 혼합 표, 백호 7간지, 괴강 경진/경술/임진/무술. 파일 blob `82739a049e76dfa2b5b9630aa928e73fd32968db`.
- [rath/orrery 기둥 계산](https://github.com/rath/orrery/blob/b49bffb0e7031ce5b7a3a71e317f5cf9ffc6cf3a/packages/core/src/pillars.ts): 12신살 연지 기준의 비교 자료. blob `1e40daad36f66b467dd05a3410566cbf6383b7ec`.
- [ganji-saju 신살 비교 구현](https://github.com/ganji-saju/ganji-saju/blob/50b3eac647e168e78a60dd99e7603636a2480c71/src/lib/today-fortune/sinsal-comprehensive.ts): 천을·문창·백호 표 교차 확인, 일부 항목 일지 기준. 괴강에 임술을 포함하고 천덕은 천간 일부만 다루는 등 차이를 확인했다. blob `3943f18dcb7e63f10979396185bbf97ce3a622ac`.

orrery는 AGPL-3.0이다. 외부 구현의 코드·설명 문구·점수·판정 로직을 복사하거나 의존성으로 추가하지 않았다. 전통 대응표의 사실관계를 참고해 독립 구현했으며 문구는 새로 작성했다. 조회한 다른 공개 구현 중 백호를 충 관계로 단순화하거나 지지 하나로 판별하는 사례는 채택하지 않았다.

백호를 원국 일주 밖에 표시하는 것은 조사 자료의 일주 기준을 확장한 **제품의 간지 비교 범위**다. 보편적인 학파 규칙으로 포장하지 않고 각 해당 항목 근거와 기준 선택에 확장 방식이라고 적었다. 괴강의 상충된 목록도 화면에서 채택 목록을 밝힌다. 다른 앱과 동일하다고 보장하지 않는다.
