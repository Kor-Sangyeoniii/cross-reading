# CR-027 — 내 삶의 질문과 대화로 연결하기

2026-10-19 사용자 요청: 만화 장면이 무엇을 설명하는지 불분명하다. 본인의 기질, 대운의 작용, 직업·연애·금전·성공 분야를 직접 설명하고 점수로 볼 수 있어야 한다. 친구와 조합, 대화 분석, 추천 답변도 원한다.

## 화면 구성

| 위치 | 사용 흐름 |
| --- | --- |
| 내 사주 / 내 기질 | 일간의 뜻 → 월간으로 보는 일하는 모습·일지로 보는 친밀한 관계 → 분야별 참고지수와 펼치는 설명 |
| 일·월·연·대운 | 기존 날짜·계산 기준·구간 선택 → 분야별 해설과 원국/기간 지수 비교 → 기존 이야기·만세력·신살 상세 |
| 내 사주 | 친구 조합 열기 → 동의한 양력 출생일·시간·선택 MBTI → 실제 궁합 규칙의 공통점·차이·질문 |
| 체험의 대화 / 계정의 내 사주 | 카카오톡 텍스트 불러오기·붙여넣기 → 동의 → 인식된 참여자/메시지 확인 → 나 선택 → 상대 메시지 선택 → 답변 초안 |
| 계정의 방 대화 | 메시지마다 답변 추천, 이 방 대화 분석하기 → 동의 → 현재 접근 가능한 메시지만 분석 → 채팅 입력칸에 초안 넣기 |
| 소개 체험의 대화 | 미리 작성된 상대 예시 메시지에 답변 추천 → 인사 입력칸에만 넣기 |

친구 입력과 대화 불러오기는 별도 기능이다. 친구의 사주·MBTI로 실제 대화의 의도나 감정을 판정하지 않는다. 이전 원국·신살·만화 설명은 계속 열 수 있다.

## 점수의 의미와 계산

이번 사용자 요청이 앞선 무점수 지시보다 우선한다. AGENTS.md 등 확정 정책 파일은 임의 수정하지 않았다. 이번에 추가한 수치는 **해당 주제에 연결한 십성이 얼마나 나타나는가**를 보여주는 앱의 편집 지수이며, 행운·성공 확률·수익·건강·관계 안전성의 측정값이 아니다. 높음=좋음, 낮음=나쁨으로 읽지 않도록 카드 바로 위와 계산 근거에서 설명한다.

- 원국: 일간을 제외한 확인된 천간과 지지 대표 지장간 관계 7개, 시간 미상은 5개. 모든 자리를 동일 가중치로 사용.
- 기본 가중치 1, 분야별 지정한 십성은 2. 합계 / (자리 수 × 2) × 100. 가능한 범위는 50~100. 마지막에 반올림한다.
- 직업: 정관·편관·정인·식신 / 연애: 비견·식신·정재·정인 / 금전: 정재·편재·겁재·식신 / 성취: 상관·편인·편관·비견.
- 기간: 해당 운의 천간·지지 관계를 같은 가중치로 계산. 원국 70% + 기간 30%, **반올림 전 값으로 합산 후** 마지막에 반올림. 화면의 원국 단독 값은 표시용 반올림값이다.
- 이 분야 배정과 비율은 명리학의 확정 공식이 아닌 제품의 편집 선택이며 과학적으로 검증되지 않았다. 신강약·조후·용신을 계산한 종합 길흉 점수가 아니다. MBTI는 지수에 넣지 않는다.
- 날짜 오류, 대운 기준 미선택, 시간 미상으로 대운 산출 불가이면 운의 지수를 만들지 않는다. 절기 경계는 확인 필요 표시.

글의 근거: 직업은 월주 천간, 연애는 일지, 금전은 확인된 재성의 첫 자리(없으면 월주 천간), 성취는 확인된 식상 첫 자리(없으면 시주 천간, 시간 미상은 월주 천간). 첫 자리는 기존 만세력 화면 순서(시·일·월·연)를 따른다. 선택 규칙과 대체 근거를 글에 드러낸다. 각 분야의 실제 상황 예시와 조절 가능한 행동을 별도로 제공한다.

## 대화·추천의 실제 구현과 한계

**현재는 로컬 규칙 기반이며 생성형 AI 연결을 완료한 것으로 표시하지 않는다.** 사용 가능한 외부 AI 공급자·자격증명·유료 사용 승인이 없다. 실제 AI 추천에는 서버 측 공급자 설정, 비용 한도 승인, 원문 전송의 별도 동의·최소화, 삭제/보존 정책, 접근 통제와 프롬프트 인젝션 대응 검증이 필요하다. 이번 작업에서는 외부 모델을 호출하거나 비밀키 입력 화면·가짜 생성 결과를 만들지 않았다.

지원 가져오기: UTF-8 .txt 또는 직접 붙여넣기. PC `[이름] [오후 6:10] 내용`, 모바일 `2026년 10월 18일 오후 6:10, 이름 : 내용`과 점/슬래시/하이픈 날짜 구분 형태. 여러 줄 메시지를 유지하며 알려진 헤더·사진/첨부 안내를 제외한다. 모든 카카오톡 버전·언어·내보내기 형식을 지원한다고 주장하지 않는다. 카카오 계정/API에 접속하지 않는다.

- 파일 300KB, 텍스트 10만 자, 2,000메시지, 20참여자 상한. 디코딩 실패·너무 큰 파일·형식 오류는 입력을 포함하지 않는 고정 오류.
- 원문을 받아들였다고 분석을 자동 실행하지 않는다. 참여자 동의 확인 후 버튼을 누르고, 가져온 대화에서 내가 누구인지 직접 선택해야 상대 메시지를 고를 수 있다.
- 분석은 메시지 수·물음표 포함 수·평균 글자 수다. 숨은 의도·호감·인성·범죄 위험·답장 속도를 판정하지 않는다.
- 선택 메시지의 표현을 금전/민감정보, 중단/거절, 갈등, 피로/고민, 일정, 질문, 열린 대화 순서로 분류하여 정해진 답변 2개와 추천 이유를 제공한다. 단어 규칙이라 인용·농담·부정 표현을 정확히 구별하지 못할 수 있고 사용자 검토가 필요하다.
- 추천 선택은 편집 가능한 초안만 채운다. 계정 채팅은 기존 보내기 버튼을 사용자가 눌러야 기존 메시지 저장/알림 경로로 전송한다. 분석 기능이 별도 발송·새 DB 저장을 수행하지 않는다.
- 원문은 React 텍스트로 렌더링하고 HTML·명령을 실행하지 않는다. 분석 결과/친구 입력/대화 원문을 로컬 저장소·URL·로그·외부 API에 남기지 않는다. 분석 지우기·동의 철회·입력 변경은 결과/초안을 지운다. 새로고침하면 가져온 입력이 사라진다. 계정 채팅의 원래 DB 메시지는 분석 지우기로 삭제되지 않는다.
- 방에서는 이미 RLS/차단 필터를 거친 현재 표시 메시지만 분석한다. 삭제된 메시지의 분석 대상과 추천 초안은 표시·전송할 수 없게 하고, 참여자 식별자는 화면에서 별명으로 표시한다.

## 검증

단위 검사는 실제 원국 자리·산식·기간 변화·원국 불변, 두 가져오기 형식·여러 줄·첨부 제외·크기/인원 한계·HTML을 데이터로 처리·상황별 추천을 다룬다. 새 브라우저 검사는 합성 정보로 4분야 해설/접근성/폭, 날짜·대운 유효성, 친구 동의·변경·삭제, 대화 동의·참여자 선택·초안 편집, 파일 오류·새로고침·저장 없음, 앱 대화의 자동 전송 없음을 검사한다. 기존 계정 채팅 검사는 추천/분석의 초안 전용 동작과 메시지 삭제 후 초안 제거를 추가했다.

운영 DB·실제 사용자 대화·실제 AI·결제·유료 호출을 검증했다고 주장하지 않는다. 모든 브라우저 검사는 외부 요청을 차단하고 캡처하지 않는다. 테스트 배포는 기존 사용자 승인 범위이며 main 병합은 하지 않는다.
