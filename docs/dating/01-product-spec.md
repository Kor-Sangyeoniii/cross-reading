# Cross Reading 소개팅 파일럿 기획 v0.1

작성 2026-10-13 KST. 사용자 사업계획서 후속 실행. 기존 PROJECT/DECISIONS의 확정 기록은 수정하지 않는다.

## 제품 약속
가까운 생활권, 겹치는 시간, 같은 관계 목적을 이유로 소개한다. 두 사람이 관심을 표시한 뒤 연결비를 절반씩 낸다. 상대 미결제로 기한이 끝나면 먼저 낸 금액 전액을 환불한다. 결제는 상대의 응답·만남 의무를 구매하지 않는다. 기질 캐릭터는 대화 소재이며 인품·궁합 점수가 아니다.

## 첫 범위
- 성인19세 이상, 한 생활권부터. 기존 개인 풀이·친구방은 유지.
- 소개 프로필: 닉네임, 넓은 생활권, 가용 시간, 관계 목적, 대화 취향. 실명/연락처/생년월일/정확한 위치/인증 원본은 상대에게 노출하지 않음.
- 실제 참여는 서버가 확인한 성인·본인·사진 검토 결과와 최근7일 활동 의사가 필요. 본인 체크박스는 인증이 아니다.
- 한 번에 소수 소개, 양방향 선호와 생활권·시간·목적 확인. 미충족이면 대기; 무조건 수량을 채우지 않음.
- 예시 가격 각3,000원, 첫 결제 기준24시간. 미확정 기획값이며 실제 결제 모듈에서는 서버 설정을 기준으로 함.
- 두 사람 결제 성공 이전 채팅 금지. 결제 중복·기한 경합은 서버 단일 연결 잠금 아래 처리.
- 환불 대상/처리 중/완료를 구분. 승인 후 실패하면 운영자 재처리. 결제 웹훅만 믿지 않고 PG 조회 결과를 검증.
- 대기 취소·차단·운영 중지 시 미개설 결제는 환불 대기. 거절·미결제만으로 제재하지 않음.
- 7일 활동 재확인 실패는 추천 숨김. 재확인으로 복귀. 위험행동은 신고→검토→근거 있는 조치→소명/이의제기.
- 범죄 무이력 인증·인성 점수·100% 스캠 차단은 제공하지 않는다.

## 사용자 화면
소개 홈 → 내 소개/활동 → 추천 이유 상세 → 관심 보내기 → 서로 관심 → 비용·환불 확인 → 내 결제/상대 대기 → 대화 → 신고/차단 또는 연결 종료. 언제든 상태/환불/지원 접근 유지.

## 혼자 테스트
로그인 없이 명시적 ‘가상 체험’에 진입. 네 합성 인물을 전환해 각자의 관심·결제·메시지·신고를 조작. 브라우저 메모리만 사용하고 새로고침 시 초기화. 시간 이동으로 만료/휴면 재현. 가짜 PG 완료·운영 검토는 체험 전용으로 분리. 실제 정보 입력 안내 금지, 실전 인증/결제 배지로 오인하지 않도록 모든 화면에 체험 안내.

## 운영용 코드와 출시의 경계
서버 계약·RLS·RPC는 새 마이그레이션으로 구현하되 현재 운영 DB에 적용하지 않는다. 인증업체/PG 승인·운영 담당자·환불 규정·개인정보 처리 및 외부 리뷰 전 실제 매칭/결제는 닫혀 있다. 테스트 화면 배포는 기존 승인 범위. 실서비스 개시는 별도 승인 필요.

## 검증 기준
- 일방 호감/결제로 대화 불가, 중복 이벤트/만료 후 결제로 개설 불가, 환불 실패가 완료로 표시되지 않음.
- 타인의 상세 개인정보·대화·결제 참조·신고 내용·검토 메모 조회 금지. 자기 인증·제재 해제·가격 변경 금지.
- 차단한 쌍 재추천/대화 금지. 신고 자체가 자동 영구 제재를 만들지 않음. 제재 계정에도 환불·이의제기 경로 유지.
- 추천 근거를 설명하며 점수 미사용. 360/390/430px, 키보드, 새로고침 초기화, 기존 개인 풀이/로그인 회귀 확인.
