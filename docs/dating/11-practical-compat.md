# CR-028 — 장점과 갈등을 행동으로 설명하는 조합

사용자는 조합 설명이 불분명하고 현실적인 장면과 나쁜 부분을 풀어갈 방법이 부족하다고 지적했다. “다를 수 있다”는 짧은 문장을 실제 비교 근거별로 **좋은 점 → 나쁘게 작용하는 행동 → 생활 장면 → 피할 말/대신 할 말 → 함께 할 세 단계 → 개선되지 않을 때 확인할 것**으로 확장했다.

## 적용 범위

친구 출생정보를 입력하는 `FriendExplorer`와 로그인한 방의 `ChemistryCard`가 같은 `PracticalCompat`를 사용한다. 원래의 친구 입력 동의, 비교 계산, 캐릭터, 익명 공유, 방 접근 통제, 대화 질문과 초안 기능은 유지한다. 실제 사주 비교가 없는 소개 시뮬레이션에 가상의 사주 근거를 추가하지 않는다.

## 근거와 생활 장면

| 실제 비교 근거 | 좋은 점과 주의점 | 구체적인 해결 방향 |
| --- | --- | --- |
| 일지 충 | 서로 다른 생활 리듬 / 늦은 변경으로 상대 시간을 낭비 | 불편 확인 → 변경 통보 시점·대안 합의 → 다음 약속에서 확인 |
| 오행 상극 | 서로의 계획 검토 / 검열·훈수·결정권 독점 | 실제 제약 구분 → 결정 범위 나누기 → 평가 후 역할 교대 |
| 같은 일간 오행 | 설명하기 편함 / 같은 취향이라고 확인 생략 | 공통 취향과 싫은 조건 분리 → 선택권 나누기 → 가정 확인 |
| 상생 | 도움을 주고받음 / 예약·연락·정산의 일방 전담 | 실제 부담 목록 → 준비 교대 → 행동 변화 확인 |
| 천간합 | 호감을 나눌 출발점 / 분위기로 책임·관계 속도를 짐작 | 원하는 관계 확인 → 속도 합의 → 작은 약속의 이행 확인 |
| 일지 육합 | 함께 생활하기 편함 / 배려와 불편 표현 생략 | 반복 부담 확인 → 이동·준비 교대 → 기본 방식 갱신 |
| 오행 보완 | 서로 배우고 역할 나눔 / 성향으로 역할 강요 | 역량·의사·여유 구분 → 작업 범위 합의 → 교대 가능성 확인 |
| MBTI E/I 같음·다름 | 회복 방식에 공통점 또는 차이 / 피곤함을 애정으로 판단 | 실제 여유 질문, 함께할 시간·혼자 쉴 시간 합의 |
| MBTI S/N 같음·다름 | 관점 공유 또는 보완 / 조건·목적 누락, 아이디어를 무시 | 대화 목적 확인, 큰 그림과 실행 조건 순서 나누기 |
| MBTI T/F 같음·다름 | 위로·조언 방식의 공통점 또는 차이 / 원치 않는 평가·조언 | 듣기·의견·구체적 도움 중 원하는 것 확인 |
| MBTI J/P 같음·다름 | 계획 방식의 공통점 또는 차이 / 준비 누락·변경 비용 전가 | 담당 명시, 고정 조건·자유 시간을 분리 |

사주 7종과 MBTI 4차원의 같음/다름 8종, 총 15종의 원고다. 같은 유형과 다른 유형에 동일한 갈등 장면을 재사용하지 않는다. 코드만으로 누가 계획형/즉흥형인지 또는 누가 더 희생하는지 정하지 않는다. 장면의 역할은 예시이며 실제 당사자에게 일어난 일을 분석한 것처럼 말하지 않는다.

## 표시와 한계

- 첫 요약에 활용할 장점과 먼저 조율할 차이를 함께 보여준다. 차이 항목이 먼저 나오지만 위험도·궁합 순위가 아니다. 장점으로 갈등을 상쇄하지 않는다.
- 모든 항목에서 좋은 점과 “이렇게 되면 나빠요”를 바로 읽을 수 있다. 생활 장면·대사·세 단계·재검토 기준은 펼쳐 읽고 첫 항목은 기본으로 열린다.
- 실제 비교 사실의 `code`와 `kind`로만 원고를 선택한다. 코드가 없거나 지원하지 않는 조합이면 장면을 꾸며내지 않고 추가 근거로만 보여준다.
- 오행 보완이 여러 글자에서 나와도 같은 원고를 반복하지 않는다. 서로 다른 원문 근거는 모두 보존한다.
- 출생시간 미상·절기 경계·MBTI 비공개 등의 기존 주의 사항은 상세 아래에 묻지 않고 해설 앞에 둔다.
- 차이 항목 없음은 완벽한 관계, 공통점 없음은 나쁜 관계라는 뜻이 아니다. 그 상태를 명시하고 실제 경험을 확인하도록 한다.
- 직접적인 평가는 **행동의 비용과 상호 존중**에 대한 것이다. 사주·MBTI로 인격·실제 갈등·안전성·성공 여부를 판정하지 않는다. 새로운 점수나 계산 법칙을 추가하지 않았다.
- 해결 방법은 서로 동의할 작은 약속과 확인 가능한 행동으로 제안한다. 무조건 참기·한쪽의 책임·상대 설득을 해결책으로 두지 않는다. 합의가 지켜지지 않으면 함께할 범위나 관계를 재검토할 수 있다고 설명한다.
- 개인정보·추가 저장·로그·외부 생성 호출을 추가하지 않는다. 공유 이미지에는 이 원문·개인 근거를 새로 넣지 않고 기존 익명 공유 형식을 유지한다.

## 검증 범위

단위 검사는 실제 원국에서 나온 충/합/상생/상극, 동시 장점·갈등, MBTI 같음·다름·미공개, 중복 보완의 근거 보존, 알 수 없는 코드, 시간 미상과 입력 불변을 확인한다. 브라우저 검사는 친구 입력 변경 후 낡은 장면 제거, 해설·원문 근거 일치, 세 단계 해결법, 키보드·360/390/430px, 동의 철회·초기화·저장 없음, 실제 계정 경로의 공통 화면·자동 발송 없음, 기존 공유·채팅 회귀를 확인한다. 가짜 데이터만 사용하고 캡처·외부 발송을 수행하지 않는다.
