# CR-024 — 출생일 달력·MBTI 선택

2026-10-14 KST. `/try`의 고정 출생정보를 바꿔 개인 풀이를 비교할 수 있게 했다.

## 사용 방법

1. 오늘 화면의 **출생일·MBTI 바꾸기**, 또는 **내 사주 / 마이**를 연다.
2. **출생일 · 양력**에서 달력을 열어 날짜를 고른다. 출생시간을 고르거나 **시간을 몰라요**를 체크한다.
3. MBTI16유형 또는 **아직 몰라요 / 선택 안 함**을 고른다.
4. **선택한 정보로 풀이 보기**를 누른다. 마이에서 적용하면 내 사주로 이동한다.
5. 캐릭터·오행·기질·원국/십신·일/월/연간·대운은 적용된 출생정보를 사용한다. MBTI는 직접 선택한 유형으로 별도 표시하며 사주 계산이나 소개 순위를 바꾸지 않는다.

출생일 선택과 운세를 살펴볼 날짜는 다른 입력이다. 후자는 기존 일별·월간·연간 상세의 날짜 선택에서 변경한다. 이번 출생일 달력은 양력 기준이다. 음력 변환 입력은 기존 실제 계정 프로필에서 제공한다.

## 입력과 개인정보

- 초깃값은 기존 합성 인물. 값을 적용하기 전에는 기존 풀이를 유지한다.
- 빈 날짜·미래 날짜·1900년 이전·누락된 시간은 안내 후 적용하지 않는다. 실제 존재하는 날짜를 검증하고 계산 실패 시 입력값을 포함하지 않는 오류를 표시한다.
- 시간 모름이면 시주가 제외되며 대운 등 필요한 시간 정보가 없는 풀이는 기존 엔진의 제한 안내를 따른다.
- 적용한 값은 탭 이동 중 유지하지만 새로고침하면 합성 초깃값으로 돌아간다. 서버, localStorage/sessionStorage, URL, 진단 로그에 출생정보나 MBTI를 기록하지 않는다.
- 실제 계정 생성/프로필 수정/DB 마이그레이션 없음. 소개 안내·결제·메시지는 기존 가상 동작을 유지한다.
