PortOne은 후보 연동 규격이지 계약 확정이 아니다. 소개팅 업종 취급 가능 여부·최소료·정확한 수수료·취소비용은 아직 미확인. 키를 넣는 것만으로 실제 서비스를 활성화하지 않는다.

## 시장·대안 조사 상태
- ppippi.me: 사용자가 제시한 레퍼런스. 실제 최신 기능/가격은 이 환경 CONNECT403으로 확인 불가. 비슷한 외관만으로 소개팅 기능을 제공한다고 추정하지 않음.
- WIPPY/Bumble/Tinder 등: 비교 후보. 가격·추천 방식·검증 정책은 원문 확인 전 우열표 작성 금지.
- 무료 대안 가설: 지인 소개, 동의 기반 커뮤니티, 무료 자기이해/AI 대화. 유료 가치 가설은 ‘기질 풀이’ 자체보다 활동 중인 성인 상대와 상호 선택한 연결 및 분쟁 대응.
- 국내 법령 최신 원문: law.go.kr 접근403. 범죄경력 조회를 구현하지 않으며 법적 허용을 단정하지 않음. 개인정보·성인확인·환불·증거 보존은 실제 영업 전 전문가 검토.
- 위 출처의 직접접근에 필요한 도메인은 환경 설정 초안에 추가. 초안 저장을 접속 성공으로 표현하지 않음.

## 기획 가설을 검증하는 조사
성인 인터뷰10명(이용 경험/피해 경험/지불 의향), 동일 조건 랜딩2안(반반 연결비 vs 정액 소개), 한 생활권30~50명 대기 등록, 상호호감/미결제/환불/재이용 이유 기록. 아직 인터뷰·설문·사용자 모집은 수행하지 않았다. 사용자/외부인에게 자동 연락하지 않음.

## 개발 결정
1. 독립적인 합성 체험에서 전체 흐름을 먼저 실행한다. 가짜 회원을 진짜 추천으로 섞지 않는다.
2. 실제 기능은 서버의 운영 허용 스위치·성인/사진 검토·RLS/RPC 뒤에 둔다.
3. 새 결제 시스템에 기존 친구방을 재사용하지 않는다. 기존 친구 초대로 유료 잠금을 우회하지 못하도록 별도 대화 권한을 사용한다.
4. 클라이언트에서 실거래·인증 결과·제재 판정을 생성하지 않는다. 외부 제공자 연동은 증빙 검증 인터페이스와 모의 테스트를 준비하고 실제키/계약/리뷰 없이 호출하지 않는다.
5. 공개 출시 미충족 조건은 숨기지 않고 문서와 화면에 구분한다.
