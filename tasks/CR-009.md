## 설계
- 서버 함수 `delete-account`: 호출자 JWT로 본인 확인 → 확인 문구(`DELETE_MY_ACCOUNT`)와 **최근 15분 안 로그인** 검사 → `auth.admin.deleteUser(본인, 완전 삭제)`
- DB 외래키 CASCADE로 삭제: profiles, room_members, messages(보낸 것), push_subscriptions, blocks, invites(만든 것), reports(내가 한 신고)
  - 남는 것: rooms.created_by·reports.reported_user_id는 비워짐(SET NULL). 다른 사람의 메시지는 그대로.
- 브라우저 `deleteMyAccount()`: 서버 함수 호출 후 이 기기 세션 정리. `reauth_required`면 화면이 다시 로그인시킨 뒤 재시도.
- 이 방식은 CR-002의 SQL 함수(delete_my_account)를 대신한다(그 함수는 MCP 제약으로 적용하지 않았음).
