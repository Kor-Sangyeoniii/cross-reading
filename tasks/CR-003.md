## 상연님 콘솔 설정 (본인 계정으로만 가능, 비밀키는 채팅·Git에 붙여넣지 않음)
1. 카카오 개발자(developers.kakao.com): 앱 생성 → REST API 키 확인 → 그 키의 "카카오 로그인 Redirect URI"에
   `https://bfntkulpspknuuwmnhfx.supabase.co/auth/v1/callback` 등록 → 클라이언트 시크릿 활성화
   → 카카오 로그인 상태 ON → 동의항목: 닉네임(profile_nickname), 프로필 사진(profile_image)
2. 구글(console.cloud.google.com): 프로젝트 → Google Auth Platform에서 대상(외부)·브랜딩 설정 →
   OAuth 클라이언트(웹 애플리케이션) 생성 → 승인된 리디렉션 URI에 위 Supabase 주소 등록
3. Supabase 대시보드 → Authentication → Sign In / Providers:
   Kakao 켜기(Client ID=REST API 키, Secret=클라이언트 시크릿, "Allow users without an email" 켜기),
   Google 켜기(Client ID·Secret 입력)
4. Supabase → Authentication → URL Configuration: Redirect URLs에 `http://localhost:5173/**` 추가 (배포 주소는 배포 때 추가)
